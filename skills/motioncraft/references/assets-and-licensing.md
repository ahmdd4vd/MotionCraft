# Assets and licensing

## What you can use

| Asset | OK | Not OK |
|---|---|---|
| Music | motioncraft `music make`; CC0 / public-domain tracks with the source noted | any commercial or "free for YouTube" track without a clear license |
| SFX | motioncraft `sfx make`; CC0 packs | ripped sounds from apps or games |
| Fonts | Google Fonts (open licenses), fonts the user owns | paid fonts without a license |
| Logos | official press-kit / brand-asset pages, used to refer to that product | modified logos, logos implying endorsement |
| Screenshots | real screenshots you or the user took; credit other products | fake UIs presented as a real product |
| Icons | open icon sets (for example Lucide, Tabler, Phosphor) under their license | emoji as UI icons (style rule, not license) |
| 3D | the template's own shapes, `Logo3D` from an SVG, CC0 models | models with unclear licenses |
| Footage from a reference video | short clip, credited, only when you are commenting on it | reusing it as your own content |

## Rules

- Keep a `CREDITS.md` (or a note in `brief.md`) in each project listing every third-party asset and its source.
- Put a `<Credit>` on screen for third-party numbers, screenshots and clips.
- Logos go in `public/`. Prefer SVG; `Logo3D` needs a clean single-path SVG.
- Remotion itself: free for individuals and small companies, company license for larger teams - see https://www.remotion.dev/license.
