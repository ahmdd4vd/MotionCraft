# Script and structure

## Default structure (30-90 s)

| Part | Time | Job | Pattern |
|---|---|---|---|
| Hook | 0-3 s | stop the scroll | a bold claim, a question, or a surprising visual |
| Reframe | 3-10 s | change how they see it | "Not X. Y." |
| Proof | 10-35 s | show it working | UI cards, numbers with credits, before/after |
| How / formula | 35-50 s | make it usable | 3 steps, one card each |
| CTA | last 5-8 s | one action | "Comment X", "Follow for more", "Link in bio" |
| End card | 2-3 s | who made it | handle + one line |

Shorter video? Cut the formula, keep hook -> proof -> CTA.

## Writing rules

- One idea per sentence, 8-14 words.
- Talk like a person. No "Unlock", "Revolutionize", "Game-changer", "In today's fast-paced world".
- Concrete beats clever: "renders in 40 seconds" beats "blazing fast".
- The hook must work with the sound off - the first headline carries it alone.
- End on the action, not on a summary.

## Scene list

Write it next to the script, one row per line:

```
0:00  "Make videos like this."         h1 center + FloatingShapes
0:03  "The secret is not prompts."     Strike "prompts."
0:05  "References."                    h0, accent
...
```

Each row names a component from the template. If a line has no visual idea, the line is probably filler - cut it.

## Length check

Spoken English runs about 2.5 words per second. A 60 s video fits roughly 130-150 words of voiceover, less if there are musical pauses.
