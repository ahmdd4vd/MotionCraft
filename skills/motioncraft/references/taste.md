# Taste

What separates a designed video from an "AI slop" one. Check every frame against this.

## Looks generated (avoid)

- Colored blurry blobs everywhere as the background
- Inter or the system default font for everything
- Emoji used as icons
- Fake CSS 3D (flat cards spun on an axis) instead of real lit 3D or none
- Every word popping with a bounce
- Gradients on text, glows on everything, 4+ accent colors
- Stock phrases: "Unlock", "Supercharge", "Revolutionize", "Seamless"
- Text wall: 3+ lines, small type, centered on a busy visual
- Numbers with no source
- Every element moving at once

## Looks designed (aim for)

- One accent color, used for one word per sentence
- Lots of empty space; the frame breathes
- Clear hierarchy: one big thing, one supporting thing
- Words appear exactly when spoken, rising softly out of blur
- A few real objects (UI cards, logos, lit 3D shapes) that mean something
- Slow camera drift so nothing is ever frozen
- Transitions that carry motion from one scene into the next
- Sound that you notice only when it's missing

## Before you send, ask

1. Would a designer screenshot any frame of this for inspiration?
2. Is there anything on screen that doesn't help the sentence being spoken?
3. Does the first frame make sense with the sound off?
4. Does the video look like *this style*, or like every other AI video?

If any answer is no, fix that first.
