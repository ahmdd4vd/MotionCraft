# Research and topic

## Pick an angle

A good video answers one question the audience already has. Before writing:

- Who is watching and what do they already know?
- What is the one thing they should remember?
- Why now? (new release, common mistake, trend)

If the user gives only a topic, propose 2-3 angles in one line each and pick the strongest if they don't care.

## Research

- Use live sources: official docs, changelogs, release notes, the product's own site, reputable news.
- Save every fact in `research.md` with its URL and the date you checked it.
- Numbers (users, stars, prices, benchmarks) change fast. Re-check them right before the final render.
- If two sources disagree, use the official one and say so in the note to the user.
- Don't state something as fact if you only found it in one unofficial place.

## On screen

- Every number or claim from a third party gets a `<Credit>` line.
- Screenshots of other products: use real ones, credit them, never fake a UI and pass it off as real.
- If a fact can't be verified, cut it or turn it into an opinion ("feels faster") that the user agrees to.
